## 取舍

- **零依赖优先于功能齐全**：少一个依赖，就少一次「协作时 lock 文件冲突」
- **可读性优先于抽象层次**：SQL 写在眼前，N+1 在写的时候就看得见
- **一个人维护优先于社区热度**：不为假设中的贡献者写文档，只为自己三个月后还能看懂
- **不做大而全**：组件库只封装中后台真正会用的，框架只覆盖 API 服务
